T-regressor

Drop in a CSV and it automatically compares linear models, gradient-boosted trees, Gaussian processes, and neural nets to pick the best-fitting model — a fully browser-based AutoML tool. It runs on Pyodide (Python compiled to WebAssembly), so no server is needed and no data ever leaves your browser. After training you can inspect R², RMSE, and feature importance instantly, making it easy to use on real-world data even without ML expertise.CSVをドロップするだけで、線形・勾配ブースティング木・ガウス過程・ニューラルネットを自動比較し最良のモデルを選ぶブラウザ完結のAutoMLツール。Pyodide（PythonをWebAssemblyにコンパイル）で動作するためサーバー不要・データは一切外部に送信されない。学習後はR²・RMSE・特徴量重要度をその場で確認でき、専門知識がなくても実務データで扱いやすい。

T-Oracle

Drop in a CSV and T-Oracle trains a surrogate model on the spot, then suggests the next points worth sampling — either to chase the optimum or to sharpen the model where it is least certain. Trade-offs across variables show up live as pairwise contour maps and a parallel-coordinates view, and the suggested candidates can be exported directly. A hands-on take on the Bayesian Active Learning and Set-Based Concurrent Engineering methods used in automotive design, built to run entirely in the browser.CSVをドロップするだけでT-Oracleがその場でサロゲートモデルを学習し、次にサンプリングすべき点を提案する——最適解を追うか、モデルが不確かな領域の精度を上げるかを選べる。変数間のトレードオフはペアごとの等高線ヒートマップとパラレルコーディネートでその場に表示され、提案された候補点はそのまま書き出せる。自動車設計で扱うBayesian Active LearningとSet-Based Concurrent Engineeringの手法を、ブラウザだけで動く形にした個人プロジェクト。

T-RAG

A secure, offline-first RAG (Retrieval-Augmented Generation) chatbot that runs entirely on CPU without requiring internet connectivity. Designed for enterprises handling sensitive documents that cannot be exposed to external services, T-RAG enables intelligent document retrieval and question-answering while keeping all data and inference local. Perfect for confidential research, proprietary designs, and classified information workflows.インターネット接続不要で、CPU だけで完全にローカル実行される、セキュアなオフラインRAG（Retrieval-Augmented Generation）チャットボット。外部サービスに公開できない機密文書を扱う企業向けに設計されており、すべてのデータと推論をローカルに保持したまま、インテリジェントなドキュメント検索と質問応答を実現。機密研究、固有技術設計、分類情報ワークフローに最適。
